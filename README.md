# Oh-My-DLML-System

AI 에이전트로 DL/ML 작업을 할 때 지킬 원칙을 정리한다. 일반 개발·Git·보안 원칙은 [Oh-My-System](https://github.com/sngmng6506/Oh-My-System)을 따르고, 이 저장소에는 DL/ML에만 해당하는 내용만 둔다. 데이터·모델·실험의 세부 사항은 각 프로젝트에서 관리한다.


## 문서

| 문서 | 내용 |
| --- | --- |
| [ML_PRINCIPLES.md](ML_PRINCIPLES.md) | 평가, 데이터, 실험 기록, 결과 보고, 학습 비용에 관한 원칙 |


## 프로젝트에 적용하기

CLI에서 프로젝트 열고 다음처럼 요청한다.

> sngmng6506/Oh-My-DLML-System 저장소를 참고해줘. 이번 작업과 관련된 원칙을 확인해서 적용해줘.

새 대화를 시작할 때는 다시 요청한다.

매번 요청하는 대신 프로젝트에 작업 지침을 두고 싶다면 루트에 [AGENTS.md 예시](examples/AGENTS.md)를 복사한다. Claude Code에서도 사용하려면 [CLAUDE.md 예시](examples/CLAUDE.md)를 함께 복사할 수 있다. 예시의 링크는 문서 내용을 자동으로 불러오지 않으므로, 관련 작업에서 링크를 열 수 있어야 한다.
