# Oh-My-DLML-System

AI 에이전트의 DL/ML 작업 원칙. 일반 개발·Git·보안은 [Oh-My-System](https://github.com/sngmng6506/Oh-My-System)을 따르며, 데이터·모델·실험의 세부 사항은 각 프로젝트에서 관리한다.

## 문서

| 문서 | 적용 작업 |
| --- | --- |
| [ML_PRINCIPLES.md](ML_PRINCIPLES.md) | 데이터·학습·평가·실험 |
| [SERVING_PRINCIPLES.md](SERVING_PRINCIPLES.md) | 모델 서빙·배포 |
| [LLM_APP_PRINCIPLES.md](LLM_APP_PRINCIPLES.md) | 프롬프트·RAG·에이전트·파인튜닝 |
| [MCP.md](MCP.md) | MCP 검토 |
| [SKILLS.md](SKILLS.md) | Skill 검토 |

## 적용

CLI에서 요청:

> sngmng6506/Oh-My-DLML-System 저장소를 참고해줘. 이번 작업과 관련된 원칙을 확인해서 적용해줘.

새 대화에서는 다시 요청한다. 반복 적용하려면 프로젝트 루트에 [AGENTS.md](examples/AGENTS.md)를 복사하고, Claude Code에서는 [CLAUDE.md](examples/CLAUDE.md)도 복사한다. 링크는 자동 로드되지 않으므로 관련 문서를 직접 열어야 한다.
